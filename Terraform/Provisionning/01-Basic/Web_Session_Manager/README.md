# Web Session Manager

Connects the Bastion to a WALLIX Web Session Manager (WSM): the Bastion gets the host name of the WSM and, optionally, its JWE public key, and generates its own signature (JWS) key pair. Requires API v3.12 (Bastion 12.2 or later).

## What it creates

Nothing new: there is one WSM configuration per Bastion, and Terraform sets it.

```text
WSM settings (Bastion-wide)
  ├── hostname:   wsm.example.com
  ├── jwe_public: JWE public key of the WSM (optional)
  └── jws_public: signature public key, generated by the Bastion (output jws_public_key)
```

## Run it

Prerequisites and the connection settings are described in the [Provisionning README](../../README.md#before-you-start).

```bash
cp config.tfvars.example config.tfvars           # set bastion_info_ip and wsm_hostname
export TF_VAR_bastion_info_token="<API key>"
export TF_VAR_wsm_jwe_public_key="$(cat wsm-jwe-public.pem)"   # optional

terraform init
terraform apply -var-file=config.tfvars

terraform output -raw jws_public_key             # signature public key of the Bastion
```

## Things to know

- **The settings are Bastion-wide, and destroy doesn't restore them**: `terraform destroy` only removes them from the state (the API can't delete them), and the Bastion keeps the last values applied (checked on a Bastion 12.4.3).
- **Unset means empty**: a null `wsm_jwe_public_key` removes the JWE key from the Bastion, even one set in the web UI.
- **The signature key pair doesn't change** when Terraform applies the settings: the API only regenerates it on an explicit request, which the provider doesn't send (`jws_public` was the same before and after the test). `jws_private` always reads back as `********`.

## Requirements

| Name | Version |
| ---- | ------- |
| terraform | >= 1.5.0 |
| wallix-bastion | ~> 0.17.0 |

## Resources

| Name | Type |
| ---- | ---- |
| [wallix-bastion_config_wsm.main](https://registry.terraform.io/providers/wallix/wallix-bastion/latest/docs/resources/config_wsm) | resource |

## Inputs

| Name | Description | Type | Default | Required |
| ---- | ----------- | ---- | ------- | :------: |
| bastion\_info\_ip | IP address or FQDN of the Bastion. | `string` | n/a | yes |
| bastion\_info\_api\_version | Version of the REST API. The Web Session Manager settings require v3.12. | `string` | `"v3.12"` | no |
| bastion\_info\_insecure\_skip\_verify | Skip the TLS certificate check. Only for a lab Bastion with a self-signed certificate. | `bool` | `false` | no |
| bastion\_info\_password | Password of bastion\_info\_user, when no API key is used. | `string` | `null` | no |
| bastion\_info\_port | HTTPS port of the Bastion REST API. | `number` | `443` | no |
| bastion\_info\_token | API key of bastion\_info\_user. Set this or bastion\_info\_password, preferably with TF\_VAR\_bastion\_info\_token. | `string` | `null` | no |
| bastion\_info\_user | Bastion user that owns the API key (or logs in with bastion\_info\_password). | `string` | `"admin"` | no |
| wsm\_hostname | FQDN of the Web Session Manager. | `string` | `"wsm.example.com"` | no |
| wsm\_jwe\_public\_key | JWE public key of the Web Session Manager (PEM). null: none. | `string` | `null` | no |

## Outputs

| Name | Description |
| ---- | ----------- |
| jws\_public\_key | Public key of the signature (JWS) key pair, generated by the Bastion. |
